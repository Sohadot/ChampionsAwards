## 5. Domain-boundary audit

The question: **is Mathematics & Computing one governance domain, or two recognition cultures under one label?**

Entries in a composite domain now declare which side they sit on. Measured:

| Subfield | Cases | Systems |
| --- | --- | --- |
| mathematics | 1 | 1 (Fields Medal) |
| computing | **0** | 1 (Turing Award) |
| cross-cutting | 0 | 1 (Wolf Prize) |

Findings, all observations and none of them a gate:

- **The computing side has no cases at all.** The domain could reach ten cases, three systems and an award anatomy without a single computing case, and nothing in the record would have shown it. It shows now.
- **Cross-domain comparison inside this domain is not yet meaningful.** A median gap computed across both halves would currently be a mathematics figure wearing a composite label.
- **The systems are already split one-and-one.** Fields is mathematics, Turing is computing, Wolf is cross-cutting — so the RLS threshold of three is met with only one system per side, which is exactly the shape that can hide an empty half.

> **Domain maturity threshold does not by itself establish subfield coverage.**

The Definition of Done is unchanged. No criterion was added, and an uneven split
blocks nothing. What is refused is the silence — a maturity claim that does not
say which half of its own name it rests on.
